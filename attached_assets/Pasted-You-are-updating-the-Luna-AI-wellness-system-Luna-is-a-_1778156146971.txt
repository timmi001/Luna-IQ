## 🔌 DAILY INSIGHT LOGIC

When user logs data:

### STEP 1:
Check if today's insight already exists.

---

### IF NO INSIGHT EXISTS TODAY:
Generate ONE full personalized insight using Gemini.

The insight must include:
1. Insight
2. Pattern awareness
3. Gentle suggestion
4. Emotional reassurance

Save it in the database.

Return it to the frontend.

---

### IF INSIGHT ALREADY EXISTS TODAY:

DO NOT regenerate the full insight.

Instead:

Analyze whether the new log is:
- minor
OR
- significant

---

## 🧠 SIGNIFICANT CHANGE RULES

Treat as significant if:
- symptoms become severe
- mood changes drastically
- multiple new symptoms are added
- emotional state worsens noticeably

Example:
- calm → anxious
- mild cramps → severe cramps + fatigue

---

## 🧠 IF CHANGE IS MINOR

DO NOT call Gemini.

Return a lightweight supportive response using backend logic.

Examples:
- "Noted 💜"
- "Take things gently today."
- "Your body may need extra rest tonight."

These should be short and emotionally supportive.

---

## 🧠 IF CHANGE IS SIGNIFICANT

Call Gemini to generate a SHORT same-day update.

This is NOT a full insight rewrite.

It should:
- acknowledge the change
- feel supportive
- remain concise (1–3 sentences)

Example:
"I noticed your symptoms became stronger later today. Your body may need extra care and rest tonight 💜"

Store update if needed.

---

## 🚫 NO RANDOM INSIGHTS RULE

VERY IMPORTANT:

If a user has NOT logged:
- mood
- symptoms
- cycle data
OR there is no meaningful daily log,

THEN:

- DO NOT generate any insight
- DO NOT hallucinate patterns
- DO NOT create fake wellness updates

Instead:

Return a gentle logging encouragement message.

Examples:
- "I’d love to understand how you’re feeling today 💜"
- "Log today’s mood or symptoms so I can support you better."
- "Once you add today’s log, I’ll be able to give you personalized insights."

These responses should feel:
- soft
- supportive
- non-pushy
- emotionally warm
