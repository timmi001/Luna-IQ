- AI chat assistant (Coze embedded but fully integrated visually)

- Cycle tracking

🔌 COZE EMBED WRAPPER (CRITICAL FEATURE)
-------------------------
Inside the chat page, create a full-screen iframe container:

<div style="width:100%; height:100vh; background: linear-gradient(180deg, #FFF7FB, #F6F0FF);">
  <iframe
    src="COZE_BOT_URL_PLACEHOLDER"
    style="width:100%; height:100%; border:none; border-radius:0px;"
  />
</div>

IMPORTANT:
- This iframe must look like it is part of the app
- No borders, no gaps, no browser feel
- Full-screen immersive experience
- Wrapped inside app header UI

This makes Coze feel like a native AI engine inside the app.
